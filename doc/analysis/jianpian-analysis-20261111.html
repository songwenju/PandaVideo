    荐片 macOS 5.0.4 · 实际 ASAR 功能、网络接口与播放缓存链路

    荐片 macOS 5.0.4 · 实际 ASAR 功能、网络接口与播放缓存链路¶

    目标：用户指定的 com.jianpian.macos；附件 app.asar；分析日期：2026-11-11。附件内 package.json 确认名称 jianpian、版本 5.0.4、入口 src/main/index.js，但 ASAR 不含 Info.plist，无法独立核对 bundle identifier、应用签名或 Electron 运行时版本。

    结论¶

    本附件实现了服务端驱动的影视浏览、分类、搜索、详情及播放器；非 HTTP 播放依赖包外 JPEngine2，下载逻辑存在但正常界面入口未确认。所有网络结论为静态代码确认，动态验证请求为 0。

    关键发现 关注标识与意义 证据与边界
    首页、分类、搜索、详情、短视频、上映表、专题、排行榜、求片榜、个人中心存在真实路由与调用点 重点关注：本 macOS 附件的产品功能 E2/E3；不是同名 Android 实现
    业务服务器经缓存、固定域名、远程列表、DNS TXT 和日期派生候选发现 重点关注：接口域名不能固定成一个常量 E3；实际选中域名未验证
    业务签名为 MD5(版本号 + 秒级时间戳 + 初始化 secret)，用户 token 按原始 URL 规则注入 重点关注：请求契约与初始化依赖 E3；secret 实际值和服务端鉴权效果未知
    HTTP 媒体直接播放，其他资源经本地引擎生成 MP4 地址；FTP 类型可进入下载调度 重点关注：媒体控制面与传输面分离 E2/E3；未提供原生引擎，不能还原上游节点协议
    收藏与历史使用云端接口；启动更新和手动检查更新使用不同的平台字段选择 持续观察：登录依赖及 macOS 更新兼容性 E3；不宣称云端保存或安装已成功

    质量状态：limited，限制来自缺少 macOS 运行环境、完整应用外壳和 JPEngine2。报告不把未覆盖范围写成“未发现”，不对本功能研究做风险定级。质量冻结结果另附 quality_status.json，不能由发布成功推断证据门禁通过。

    样本与证据口径¶

    • ASAR：10,417,170 字节；SHA-256：c8b0d5c2fe0843da97d2a763d329cc4bae079e71456450e3f6eb531236d191d5；MD5：f4600dbb8935c85637d3e5bf11d86ca2。
    • 已校验 ASAR 路径与字节边界并解包 786 个文件，无 unpacked 外置条目或链接条目；这不意味着应用没有包外依赖，启动代码明确引用包外引擎。
    • 56 个 dist/assets/*.js 均通过 JavaScript 语法解析；格式化副本与原文件逐词法 token 校验结果见 source_verification.json。没有执行附件业务代码，没有请求业务服务器，也没有下载影视资源。
    • 截图仅为 182×40 的“荐片”图标与名称，不能证明页面、播放状态或版本。平台和 bundle identifier 以用户提供信息为准。
    • 静态实现 E2：存在可复核函数；静态链路 E3：找到入口、条件及请求/播放 sink；动态 E4/E5：本次均没有。caller_found 仅说明找到调用点，不保证开关开启或用户能进入该分支。

    请求封装、鉴权与加密¶

    业务请求统一走 Axios 实例，普通相对 URL 拼接 选中base + '/api'。默认超时 10 秒、请求头 platform: pc（Mac 也沿用该值）、content-type: application/x-www-form-urlencoded。GET 参数放查询，POST 普通对象由 Axios 按该类型序列化；部分表单为 FormData。注册接口另有 15 秒超时与不重试配置。网络失败可重新发现域名并最多按 retryCount=3 递减重试；绝对 URL 不走这条域名切换重试。定位 F:index-B33oKSXv.js:12676–12835，完整方法保存在清单 JSON。

    1. 初始化与签名：App.d → wo.getSysInit → GET /api/v2/sys/init 配 noSignature=true，公共响应解包后读取 secret，交给 ne.setSecret 解锁等待 Promise。其他普通请求头为 version=504、timestamp=floor(Date.now()/1000)、signature=MD5('504'+timestamp+secret) 的十六进制字符串。计算没有拼入 URL、参数或请求体，不能称为“整包内容加密”。如果初始化失败，代码仅 catch/log，没有找到签名等待 Promise 的失败释放路径；后续签名请求可能一直等待，需运行验证。定位:12709、12797、21176。
    2. token 注入：U1(rawUrl) 精确检查允许列表，或排除以 http 开头的绝对 URL。对需附加 token 的 /v2 路径，token 放请求头；其余 GET 写 params.token，POST 写 data.token 或 FormData。/usersV2/* 不含小写 /v2，因此走旧式 body/query 分支。匿名用户 token 可能为空，不能把“注入逻辑存在”解释为服务端一定要求登录。定位:7995、12706、12816。
    3. 精确匹配细节：允许列表中的 /video/detailv2、/video/guessRecommend，与实际含 ?id= 的拼接字符串不相等；某些模板路径也未列在 allowlist。签名和 token 判断以代码实际字符串为准，不能按接口名称推断免鉴权。定位:7995、21858、21881。
    4. token 存储：Pinia user store 将 userInfo JSON 保存至 localStorage，token 来源是 userInfo.token；昵称、头像、inviteCode/inviteImg 也有本地状态。不是在包内发现实际用户凭证，本报告不提取或公布凭证。定位:12572–12675。
    5. 响应契约：公共封装读取 {code,msg,data,...other}，code≠1 拒绝 {code,msg}；originalData=true 原样返回，否则返回 data；有额外顶层字段时挂到 data.other，data 为空时返回其余字段。HTTP 401 映射“请登陆”、500 映射服务端错误；这些是客户端映射，不是服务端实测状态。定位:12719–12756。
    6. 加密边界：CryptoJS 中确有 AES/DES/TripleDES 等通用算法实现，但本任务追踪到的第一方业务调用是 MD5 签名与日期候选计算；未找到这些业务请求的应用层 AES 加密/解密调用。播放器捆绑 HLS AES 解密库，仅证明支持加密 HLS 的库能力，不能证明实际影片使用该加密，更不能推断 DRM 或许可证服务。HTTPS 传输与应用层加密分开记录。
    7. 传输配置：主进程设置 disable-web-security，主窗口 sandbox=false；未在本次第一方 JavaScript 路径发现自定义证书 pin 或 TLS 验证覆盖。不能据此推断 Electron/系统验证已关闭，也不能覆盖未提供的 JPEngine2。IP 候选及 loopback 明确为 HTTP，其余固定 API 候选为 HTTPS。定位 S:main/index.js:20、145。

    播放器与本地引擎¶

    链路一，HTTP(S) 直链播放：分类/搜索卡片 → 长详情接口 → 来源与分集 → url.startsWith('http') 分支 → VideoPlayer → Video.js src/load → 浏览器媒体请求。附件捆绑 Video.js 8.22.0、@videojs/http-streaming 3.17.0、m3u8-parser 与 MPD parser，支持 MP4/HLS/DASH 的库路径；不能仅凭库存在宣称实际影片采用 HLS/DASH。普通媒体没有业务 signature 注入；VIP 条件下 R.Vhs.xhr.beforeRequest 设置 token 请求头，仅证明 VHS 请求分支，不涵盖所有原生 HTML5 MP4 请求。定位 F:VideoPlayer-9YDDWVER.js:7708、15279、27562。

    链路二，非 HTTP 播放：主进程启动包外引擎 → preload 读取临时目录 JPEngine2.lock → 本地端口 → POST create → 返回 loopback /p2p/{base64url(resource)} → 约2秒后以 video/mp4 交给 Video.js。资源编码为 UTF-8 Base64，移除 padding 并替换 + / 为 - _，不是加密。详情代码对所有非 http 开头资源都进入引擎，不仅限 FTP；下载调度却只识别 ftp://。macOS 生产启动路径为 path.dirname(process.execPath) 下 ../JPEngine2，ASAR 内未包含该二进制。定位 S:main/index.js:42–64；S:preload/index.js:43–51；F:index-B33oKSXv.js:7979、15039。
