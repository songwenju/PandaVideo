# 自动跳过片头片尾技术方案

状态：功能代码完成，测试及双端构建通过；模拟器已部署。

| --- | --- | --- |
| 本地用户数据 | 独立保存每部剧的开关及片头、片尾秒数，读取旧数据默认关闭。 | SKIP-02、03 |

不将自动跳过放在 Compose 计时器中，避免后台音频、PiP 和页面重组产生不同执行行为。

## 配置与身份

实际配置为 `SkipDurations(introSeconds, outroSeconds)`，0 秒关闭对应部分。使用稳定影片页身份，复用现有影片页规范化规则；不得仅以显示片名作为缓存键，以免同名作品串用。

片头片尾配置独立持久化，不膨胀全局 `AppSettings`。非法或损坏数据安全降级为关闭；输入长度和保存条目数受限。跨来源剧集只有在已有可靠身份关联时才能共享配置，不能按名称推断。

## 播放执行

### 片头

加载时选择初始播放位置：显式恢复/换源位置优先，再读取历史续播。自动片头跳过只补足尚未越过片头的正常开播位置，不覆盖用户主动选定的回看位置。

现有播放信息没有总时长，首版不盲目把片头位置放进初始装载参数。两类宿主均在取得有效时长并开始播放后跳过一次；宿主已有的初始续播参数保持有效。校验目标媒体 ID 和代次，过期事件不能作用于新集。

总时长未知时先保留待验证的片头配置；有效时长到达后确认不会覆盖正片。不要在未知时长时盲目传入过大的初始位置。

### 片尾

有效阈值为 `duration - outroSeconds * 1000`。只有当前媒体、正常播放意图、允许播放、无解析错误、有效时长及合法配置时才处理。

建议提取并复用现有的本集结束处理路径，由真实结束事件和片尾阈值共享；每个媒体代次最多结束一次。保留同线路集数选择、预加载、结束倒计时和取消自动连播行为。末集进入正常结束，不伪造播放器底层状态。

优先级：播放权限与暂停意图 → 定时关闭 / 播完当前 → 片尾跳过 → 自动下一集。时长定时到点与片尾同时发生时不能抢先装载下一集。

### 手动回看与换源

片头跳过使用一次性记录。对用户主动 seek 到片尾区域，需要明确的主动定位标识；不能仅由位置突变猜测操作来源，否则可能与续播和换源混淆。手动回看时暂免本集对应的自动跳过。

换线路、错误恢复和同集刷新保留本集已执行或暂免的跳过状态；真正进入另一集才重新初始化。实现时须区分“媒体代次”和“剧集身份”，不能在每次换源后重复跳过。
