# 自动跳过片头片尾

状态：已实施，自动化测试及双端构建通过；iOS 模拟器已安装启动，Android 无连接设备。

## 已确认的目标

用户希望增加自动跳过片头和片尾的功能。现有播放器具备续播、同线路自动下一集、后台音频及“播完当前”定时关闭能力。

## 首版行为

每部剧设置一次片头和片尾时长，播放器记住设置，后续各集自动执行。当前播放数据没有提供片头、片尾时间点；本方案不宣称可以自动识别画面或音乐。

| 编号 | 行为 | 验收标准 |
| --- | --- | --- |
| SKIP-01 | 播放页提供唯一“跳过片头片尾”设置入口，复用现有播放设置区域。 | 能分别开启或关闭片头、片尾；展示保存的秒数。 |
| SKIP-02 | 设置按当前剧集保存，不影响其他影片；初始关闭，不预设猜测时长。 | 重启应用和切换下一集后仍记住；首次播放其他影片不会自动跳过。 |
| SKIP-03 | 推荐输入范围为 0–300 秒；0 秒表示不跳过对应部分。 | 拒绝负数、非数字及超范围输入，错误输入不覆盖原设置。 |
| SKIP-04 | 从头播放时跳到设置的片头结束位置；有续播进度时优先保留较后的有效位置。 | 续播已超过片头时不倒退；一次播放不重复跳转。 |
| SKIP-05 | 正常播放达到“总时长减片尾时长”时结束本集，沿用同线路下一集机制。 | 不跨线路、不重复切集、不跳到无关影片；末集进入正常结束状态。 |
| SKIP-06 | 不因配置或跳过动作改变暂停意图、倍速、窗口模式或音视频模式。 | 暂停期间不会因到达片尾区域自动播放下一集；后台视频暂停策略保持有效。 |
| SKIP-07 | 手动拖回片头或片尾可以继续观看，本集不反复强制跳过。 | 手动返回已跳过区域不会形成跳转循环。 |
| SKIP-08 | 不知道总时长、不能快进，或配置覆盖整集时不执行相关跳过。 | 直播、异常时长和过短内容不会误切集；片头与片尾不能吞掉全部正片。 |
| SKIP-09 | “播完当前”优先于自动下一集。 | 若开启片尾跳过，在片尾起点视为本集正片结束并暂停，清除一次性定时，不开始下一集。 |
| SKIP-10 | 新设置从下一次加载集数起生效，关闭设置面板不触发跳转。 | 编辑时长不会突然快进或切集；下一集使用新设置。 |

## 界面文案

- 入口：跳过片头片尾。
- 说明：仅应用于当前剧集，后续各集自动跳过。
- 输入：片头时长（秒）、片尾时长（秒）；0 秒关闭对应部分。
- 时长单位：秒。
- 操作：保存、取消。

## 首版范围

支持有明确集数和可快进能力的本地播放器会话，包括 Android、iOS、音频模式和离线剧集。电影、直播、跨设备同步、遥控投屏和画面/声音智能识别暂不纳入首版。
