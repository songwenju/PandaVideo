# 熊猫视频电视版

用户于 2026-11-21 要求开发电视版，并已通过 ADB 连接小米电视。
实测设备为 MiTV4_ANSM0，Android API 23，armeabi-v7a，1280 × 720，
支持 television、leanback、遥控器方向键。现有移动端最低 API 26。

## 首版范围

以下为依据现有产品能力作出的首版工程默认范围，待用户体验后审阅；不记录为人工验收通过。

- TV-01：电视桌面有独立“熊猫视频 TV”入口，横屏启动，应用可安装到已连接电视。
- TV-02：提供精选、最近热播、分类、搜索、播放记录；复用现有高分筛选、
  已确认无资源内容过滤和片源身份匹配。电视直接连接目录及播放源。
- TV-03：方向键可进入分类、国家筛选、海报和翻页按钮；焦点清晰可见，
  确认键打开所选内容，返回键返回上一层；海报列表保留滚动位置。
- TV-04：搜索支持遥控器调起系统键盘并提交关键词，搜索结果可直接播放。
- TV-05：播放默认全屏；确认键播放/暂停，左右键快退/快进 10 秒，
  菜单键打开控制面板；面板提供选集、线路和返回目录。
  切集及线路复用现有 PlaybackSession，保持来源正确。
- TV-06：加载、空结果及网络/解析/播放失败均显示可读反馈，失败支持重试及取消。
  退出播放和切后台遵循现有会话生命周期并保存进度。
- TV-07：Android 手机入口和 iOS 界面保持原有实现；共享层旧系统兼容改动
  必须经过 host 测试、Android 构建和 iOS framework 编译。

## 验收

在 MiTV4_ANSM0 上用 ADB 方向键、确认键、返回键验证焦点导航、分类、
搜索、真实视频首帧、进度增长、暂停恢复、快进快退、选集和历史返回。
构建通过不能替代电视播放验证；网络及片源错误需记录实际原因。
人工视觉与遥控器体验验收待用户反馈。
