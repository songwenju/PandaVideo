# 随心看 · 网页版设计同步

日期：2026-11-11

本轮把网页版的品牌、内容浏览和播放入口对齐移动端，并保留网页已有的 NAS 下载能力。实现覆盖发现、最近热播、分类、独立搜索和播放页。

## 视觉与交互

| 范围 | 设计与实现 |
| --- | --- |
| 品牌 | 随心看名称；暖橙到薄荷青渐变播放图标；主操作色 `#FF6740` |
| 背景 | 浅色模式从薄荷色平滑过渡至白色；深色模式使用深灰表面 |
| 导航 | 桌面顶部发现 / 最近热播 / 分类；手机底部导航，保留安全区域 |
| 搜索 | 首页搜索框，热播与分类圆角搜索入口；独立结果页；统一跨类型搜索 |
| 海报 | 4 / 3 / 2 列随窗口宽度变化；影片名称加粗；年份灰色；评分同标题色加粗 |
| 分类 | 电影、电视剧、纪录片、动画平铺；题材与年份横向滚动；选中项橙色，圆角 8px；移除重复的“已选”和年度热门入口 |
| 搜索结果 | 播放、下载、复制按资源能力显示；图标与文字居中；搜索完成后等待用户选择影片 |
| 播放 | 点击海报后匹配播放地址；匹配失败提供继续搜索；播放进度与选集使用橙色；保留全屏、倍速、线路切换和自动连播 |
| 外观 | 跟随系统 → 浅色 → 深色循环切换；保存在当前浏览器 |
| 异常 | 刷新失败保留已展示影片；筛选失败明确提示正在显示上次结果，避免误认为当前筛选成功 |

共享外壳与卡片位于 `static/site.js`，统一样式位于 `static/suixinkan.css`。页面沿用现有 Python 服务、海报代理与播放器，实现集中配色和组件规范。

## NAS 下载

全站右上角保留一个“NAS 下载”入口，弹窗包含目标目录、挂载状态、迅雷状态、挂载按钮和手动下载链接表单。播放页另有“查找下载资源”，直接带片名进入搜索结果。

- 搜索下载：`POST /api/download`，使用搜索结果 token。
- 复制链接：`POST /api/download/copy`，剪贴板失败时保留手动复制提示。
- 手动调用迅雷：`POST /api/download/xunlei`，支持现有链接格式。
- NAS 挂载：`POST /api/nas/mount`；不支持挂载的服务器隐藏按钮。
- 下载进度继续在迅雷查看。保存目录由迅雷设置决定，需选择已挂载的 NAS 目录。

本轮不更改下载后端、令牌校验与 MCP 行为。在线播放不会自动下载视频。

## 同步边界

“同步”指页面设计与入口对齐。浏览器与原生端仍各自保存本地状态，本轮没有新增跨设备账号、收藏、历史或头像同步。网页继续使用现有榜单分类和评分准入，未将原生端所有 19 类榜单及后台无播放资源筛选搬到网页。

## 本地运行与更新

在 `frontend/` 目录启动独立预览：

```sh
APP_HOST=127.0.0.1 APP_PORT=8767 python3 app.py
```

访问 `http://127.0.0.1:8767`。如需实际 NAS 配置，使用原有 `.env` 与 `run.sh` 启动流程。

常驻 `8766` 服务运行的是安装副本，源码修改不会自动更新该副本。要更新常驻服务，在 `frontend/` 执行 `./install-launch-agent.sh`；脚本的更新与旧服务清理行为见 README。本轮提供源码与独立预览。

## 验证

```sh
python3 -m unittest discover -s tests
node --test tests/test_list_pagination.js
```

在 `tests/browser/` 运行：

```sh
SITE_URL=http://127.0.0.1:8767 npm test
SITE_URL=http://127.0.0.1:8767 npm run test:web
```

浏览器检查覆盖五档宽度、导航、影片点击播放、搜索交互、失败保留数据、NAS 操作请求与主题持久化。媒体使用本地视频夹具，下载相关 API 使用 mock，验证不会创建真实 NAS 任务。海报采用当前服务返回的真实影片图片。

本轮结果：109 项 Python 测试、8 项分页测试、161 项播放器与布局检查、115 项设计与 NAS 操作检查通过，6 个业务脚本语法检查通过。首次全屏闲置检查出现一次瞬时失败；单独复测与随后完整回归通过，未为此修改播放器状态逻辑。

Chrome 手机窗口模拟不能代替 Safari 或实体手机验证；NAS 挂载和迅雷 MCP 的实际设备联调需在配置好的运行环境确认。
