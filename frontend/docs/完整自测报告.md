# NAS 视频完整自测报告

日期：2026-11-09  
范围：首页、分类页、播放器；本机部署及测试时可连接的 NAS 部署。  
最终本机版本：player.js v11、player.css v9；已核对服务实际返回的文件内容与源码一致。

## 结论与当前状态

本机最终版本通过 **109 项 Python 单元测试、8 项分页单元测试，以及 166 项界面与状态断言**。界面断言由原有播放器回归 92 项、新增边界断言 16 项、三页布局断言 58 项组成。断言数不等于独立业务场景数。

中央加载图标误闪、全屏底栏残留及手机触控回归通过。本次新增测试发现键盘焦点问题：通过 Tab 聚焦播放器后，快捷键未启用；已补齐焦点进入和离开的处理，在本机部署并复测通过。

**NAS 未完成最终版本同步与复测。** 测试前半段 NAS 可访问，三页布局 58 项及真实 HLS 连续播放观察通过；后续 NAS 网站连接超时，文件共享同时断开，恢复共享的尝试未成功。因此键盘修复尚未同步到 NAS，不将旧版本测试结果当作 v11 的通过结果。

## 本次发现与处理

| 发现 | 处理 | 验证 |
|---|---|---|
| 键盘聚焦播放器未启用快捷键 | 同步键盘焦点进入/离开与播放器焦点状态；脚本版本升为 v11 | 原先空格暂停断言失败，修复后空格与方向键断言通过 |
| 原测试 MP4 响应未支持字节范围，导致暂停时跳转停留在 0 | 测试夹具增加 Accept-Ranges、206、Content-Range，先验证可跳转区间 | 方向键跳转真实改变时间，通过 |
| 触屏控件 opacity 为 0 时，元素仍可能被判断为可见 | 测试改为读取实际控件状态，并等待可交互显示 | 横竖屏切换与退出场景通过 |
| 浏览器可能静音自动播放 | 音量测试比较点击前后的状态反转 | 兼容不同初始静音状态，不假设初始有声 |
