# PandaVideo 离线缓存

日期：2026-11-11。范围：Android / iOS 客户端，用户请求“添加下载或者缓存功能”。本版选择应用内视频缓存，不创建 NAS 下载任务，不导出公共下载文件。macOS 和网页下载流程不在本次实现范围。

## 使用与验收规则

1. 播放详情提供一个“缓存本集”入口，当前集成功解析后可加入任务；同一来源、影片、剧集不重复创建任务。
2. “我的 → 离线缓存”统一展示任务，支持等待、缓存中、暂停、失败和已完成状态。
3. 串行执行任务，显示进度；可暂停、继续或重试。每次开始前重新解析媒体地址，来源或集数发生变化时失败，避免缓存错误剧集。
4. 完成后可从任务列表播放，使用保存的影片和选集信息；列表内“播放”不访问原来源。连播只包含已经完成缓存的剧集。
5. 任务和影片信息持久化。进程退出后的未完成任务恢复为暂停，需用户继续。Android 可复用已缓存分片；iOS 中断后重新下载。
6. 删除需确认，删除对应任务与本地媒体。当前正在播放的剧集禁止删除，需先关闭播放器。
7. 网络、格式或存储失败不能写成完成；文件失效显示可重试错误。媒体缓存使用应用私有目录，卸载应用会删除。

首版没有后台下载完成保证、自动缓存整季、清晰度选择、Wi-Fi 限制、DRM 离线许可或 FTP / P2P 下载。缓存将占用网络流量和本地空间，保留到用户删除。上述范围为本轮实现选择，未另行进行人工产品 Review。

## 技术实现

共享 `OfflineDownloads` 负责任务索引、稳定去重、队列、状态持久化和离线解析。索引保留片名、详情、剧集和封面，媒体 URL 从索引移除。开始任务时调用现有来源解析器获取新地址。

Android 使用 Media3 的 HLS / Progressive 下载器；每集使用独立的非自动淘汰 `SimpleCache`，保存清单、分片及字节范围。直播清单不能视为完整剧集。播放时私有 `pandavideo-offline` 标识由媒体服务解析，使用无网络上游的缓存数据源；缺失文件不会自动联网补齐。播放必需的原始地址记录在应用私有媒体元数据中，不对外展示或打印。

iOS 使用 `AVAssetDownloadURLSession` 保存可播放的 HLS asset package，MP4 使用 `NSURLSessionDownloadTask` 流式写入私有文件。原生委托与 Kotlin 共享接口分离。文件位置保存为相对沙盒路径，避免安装容器 UUID 变化后失效；取消的旧任务不能发布完成结果。

播放器仍复用已有续播和暂停规则。进入后台或离开播放页的播放行为不因下载任务而改变。缓存管理入口独立于收藏、历史和 NAS 功能。

## 验证方式

共享测试覆盖串行队列、稳定去重、重启暂停、取消后旧回调、重试、来源切换保护、文件失效及无需网络的离线解析。

Android 设备测试 `OfflineMediaDeviceTest` 使用显式配置的短 HLS / MP4 夹具，完成缓存后阻断来源，检查真实解码、拖动进度和来源请求数不增长。默认设备测试不访问该夹具；需指定 `offlineFixtureBase`。

```sh
# 在 mobile/ 中配置 JDK 21 与 Android SDK 后运行
/bin/sh iosApp/build-shared.sh :shared:testAndroidHostTest :shared:jvmTest
/bin/sh iosApp/build-shared.sh :app:installChinaDebug \
  :shared:linkDebugFrameworkIosSimulatorArm64
```

## 实际验证结果

2026-11-11 执行结果：

- Android Host 测试：175 项通过，无失败。
- JVM 测试：199 项中 198 项通过，1 项未启用的在线来源探测跳过，无失败。两套测试均包含本次新增的 6 项共享离线队列测试。
- Android 实机 B3110：1 项媒体设备测试通过，同时覆盖 8 秒 HLS 与 MP4。缓存完成后让来源返回 503，验证真实首帧、媒体时长、拖动至 4 秒后继续播放、来源请求数不增长，以及删除缓存。
- Android China Debug 构建、安装及启动通过；实机点击“我的 → 离线缓存”验证入口和“暂无缓存，在播放详情中缓存本集”空态。
- 最新 iOS Simulator Arm64 共享 framework 编译通过；Xcode Debug 应用构建成功，已安装并启动到 iPhone 15 模拟器。
- iOS 真实下载完成、断网播放与拖动尚未执行设备验收，当前结果仅覆盖编译、安装及启动。

Android 设备测试命令：

```sh
/bin/sh iosApp/build-shared.sh :shared:connectedAndroidDeviceTest \
  -Pandroid.testInstrumentationRunnerArguments.offlineFixtureBase=http://127.0.0.1:8877
```

该命令需先启动测试媒体服务并配置 `adb reverse tcp:8877 tcp:8877`。测试服务、端口转发仅用于验收，不属于应用运行依赖。
