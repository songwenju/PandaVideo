# 远程配置与个人备份

入口：我的 → 播放设置。设置页现包含播放偏好、睡眠定时、青少年模式、解析规则、个人数据备份与应用更新。

## 解析规则

可复制设置中的内置规则，保存为 UTF-8 JSON 文件并部署到自行控制的 HTTPS 443 地址，再填写地址执行更新。成功后保存规则与地址，下次启动检查。没有预设远程服务器；地址未配置时使用内置规则。

```json
{
  "schema": 1,
  "revision": 1,
  "searchListClass": "stui-vodlist__media",
  "thumbnailClass": "v-thumb",
  "synopsisClass": "stui-content__desc",
  "playerVariablePrefix": "player_",
  "searchMarkers": ["阳光", "相关搜索结果"]
}
```

更新时增大 revision。schema 只支持 1，禁止旧版本回退；选择器只接受单个类名或变量前缀，不接受任意正则、脚本或源站 URL。搜索页面标识 1–4 项，每项最长 40 字。JSON 最长 65,536 字符；网络层最多读取 2 MiB 后拒绝过大响应。初始更新地址仍要求 HTTPS 443；后续 HTTP/HTTPS 跳转最多 4 次，允许跨域及非标准端口，拒绝非 Web 协议和带凭据的地址。格式、大小、网络失败保留旧配置，存储损坏回退内置。

当前只支持既有 huolot.com 播放页面结构。域名、播放路径、授权检查及媒体类型检查保留在代码中，远程规则无法关闭这些检查。原始播放 URL、DRM、VIP/points 授权或执行 JS 不属于规则能力。

## 更新通知

自行部署发布 JSON；必须包含：

| 字段 | 类型 | 要求 |
| --- | --- | --- |
| versionCode | 整数 | 大于 0；大于当前 1 才显示新版本 |
| version | 字符串 | 1–40 字，如 `0.2.0` |
| notes | 字符串 | 可省略，最多 4,000 字 |
| url | 字符串 | 真实 HTTPS 发布页面，由用户点击打开 |

填写该 JSON 地址并检查后会保存地址，后续启动自动检查。没有发布地址时不会声称存在更新，也不会自动下载或安装。发布新移动版本时同步 Android versionCode/versionName、iOS CFBundleVersion/CFBundleShortVersionString 与 UpdateStore 中的当前版本常量。桌面 jpackage 使用独立包版本 1.0.0，本页面当前展示移动产品版本。

## 个人数据导入导出

点击「导入 / 导出 JSON」打开编辑器，可复制 JSON 后保存为文件，或粘贴文件内容并「验证并导入」。这是跨端剪贴板流程，尚未接入原生文件选择器。

备份 schema 为 1，包含 profile、favorites、history、progress。排除媒体直链、规则地址、播放偏好、家长密码和观看配额。导入不覆盖已有集合，按时间与页面/剧集键合并去重；资料以导入内容为准。最多 500 收藏、50 历史、200 个进度标题、每个标题 100 剧集、JSON 1,048,576 字符。全部条目校验通过后才更新资料与集合；持久化为平台键值存储，非数据库跨键事务。

## 青少年模式边界

6 位家长密码确认后开启；密码以随机盐与迭代 SHA-256 保存，不以明文保存。错误 5 次后暂停密码验证 60 秒。每日观看预算为 40 分钟，按 UTC 日期重置，记录跨重启保留；播放页、迷你栏与系统播控恢复播放后，共享层检查配额并暂停超限播放。启用后关闭自由搜索、规则编辑、更新链接和数据导入。

该能力是本地观看保护，不能替代内容年龄分级、帐号级监管或操作系统家长控制。源站没有年龄评级；家长需主动选择内容。设备时钟修改、清除应用数据及卸载重装可以重置本地状态；后台进程被系统挂起后的时长精度尚需真机验证。
