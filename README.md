# 熊猫视频 · PandaVideo

熊猫视频是一款影视浏览与播放应用，帮助你发现想看的内容、快速找到影片，并接着上次的进度继续观看。

## 主要功能

- **发现好片**：浏览热门电影、剧集、综艺、动画和纪录片。
- **分类筛选**：按类型、地区、年份和排序方式挑选内容。
- **搜索观看**：输入片名查找影片，查看简介、选集并播放。
- **便捷播放**：支持倍速、全屏和进度调节。
- **收藏与续播**：收藏喜欢的影片，查看播放记录，继续上次的观看进度。
- **个性设置**：调整个人资料、切换深色模式，设置播放偏好。

Android 和 iOS 客户端还提供离线缓存、音频模式、画中画和投屏。你可以缓存影片后离线观看，或切换到音频模式，在后台继续听。

## 支持平台

- Android
- iPhone / iPad
- macOS
- 网页版

各平台的功能以对应客户端为准。

## 开始使用

1. 打开应用或网页版，通过热门内容、分类筛选或搜索找到影片。
2. 进入影片页面，选择想看的剧集并开始播放。
3. 在“我的”中查看历史、管理收藏和离线缓存。
